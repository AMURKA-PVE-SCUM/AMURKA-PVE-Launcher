# AMURKA PVE Launcher

## Инструкция по установке

### Шаг 1. Скачай лаунчер

Перейди в [Releases](https://github.com/AMURKA-PVE-SCUM/AMURKA-PVE-Launcher/releases/latest) и скачай файл `AMURKA-PVE-Launcher-Setup-2.1.6.exe` (или какая версия актуальна).

### Шаг 2. Установи

Запусти скачанный `.exe` файл. Нажми **«Далее»** → **«Установить»**. Готово.

### Шаг 3. Запусти лаунчер

Найди ярлык **AMURKA PVE Launcher** на рабочем столе или в меню «Пуск» и запусти его.

### Шаг 4. Путь к игре

Лаунчер автоматически найдёт SCUM. Если не нашёл:
- Нажми **«📁»** рядом с полем «Папка игры»
- Укажи папку, где лежит `SCUM.exe` (обычно `C:\Program Files (x86)\Steam\steamapps\common\SCUM`)

### Шаг 5. Скачай моды

1. Выбери категории модов, которые тебе нужны:
   - **Основные** — включены всегда, без них не работает
   - **Скорость транспорта** — быстрые машины (кому нравится)
   - **Скины одежды** — кастомная одежда
   - **Скины на оружие** — кастомное оружие
2. Нажми **«СКАЧАТЬ ВЫБРАННОЕ»**
3. Жди пока скачается (может занять время, модов много)

### Шаг 6. Запусти игру

Нажми **«ЗАПУСТИТЬ ИГРУ»**. Готово!

## Частые проблемы

**Лаунчер не находит SCUM**
→ Укажи папку вручную (см. Шаг 4). Путь должен вести до папки `SCUM` (где лежит `SCUM.exe`):
```
C:\Program Files (x86)\Steam\steamapps\common\SCUM
```
→ Если папки `~mods` нет — создай её вручную по пути:
```
C:\Program Files (x86)\Steam\steamapps\common\SCUM\SCUM\Content\Paks\~mods
```

**Моды не скачиваются**
→ Проверь интернет. Если не помогло — перезапусти лаунчер

**Игра вылетает после обновления модов**
→ Удали все моды (кнопка «УДАЛИТЬ ВСЕ МОДЫ»), затем скачай заново

**Лаунчер не открывается**
→ Попробуй запустить от имени администратора (ПКМ → «Запуск от имени администратора»)
